# OBIETTIVO

Phoenix AI non è un semplice generatore di segnali.

È una piattaforma completa capace di:

- Analizzare il mercato
- Prendere decisioni
- Aprire operazioni
- Gestire operazioni
- Chiudere operazioni
- Analizzare i risultati
- Migliorare nel tempo
