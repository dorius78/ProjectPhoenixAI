# DECISIONI PROGETTUALI

## Regole del progetto

1. Architettura completamente modulare.
2. Ogni modulo deve avere una sola responsabilità.
3. Nessun codice duplicato.
4. Ogni modifica deve essere documentata.
5. Tutti i moduli devono essere testabili singolarmente.
6. Ogni versione stabile deve essere salvata su GitHub.
7. Phoenix AI deve poter funzionare in modalità:
   - Backtest
   - Paper Trading
   - Live Trading
8. Ogni decisione dell'AI deve essere spiegabile attraverso:
   - Score
   - Confidence
   - Motivazioni
9. Lo sviluppo procede per versioni incrementali fino alla Versione 1.0 Stable.
10. Il repository GitHub è l'unica fonte ufficiale del progetto.
