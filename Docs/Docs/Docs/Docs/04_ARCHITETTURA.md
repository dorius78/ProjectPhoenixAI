## Filosofia

Phoenix AI è progettato con architettura completamente modulare.

Ogni modulo deve:

- avere una sola responsabilità;
- essere indipendente;
- essere facilmente sostituibile;
- essere testabile singolarmente;
- essere documentato.

L'obiettivo è costruire una piattaforma professionale di trading algoritmico AI facilmente espandibile fino alla Versione 1.0 Stable.
